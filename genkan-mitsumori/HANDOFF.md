# 玄関見積LP シンプルUIと価格説明の引継ぎ

## 対象と変更範囲

対象は `genkan-mitsumori/index.html` と公開URL https://tomof-source.github.io/fkenzai-lp/genkan-mitsumori/ です。別の `genkan-mitsumori-codex` や他の商品LPは変更しません。

基準コミットは `f77c20a9343f07e3fb6e84bc1a47814b32cf4257`。その時点の対象HTMLのblobは `3c519b73af7ff4e8131e576070508043b72e6077`、data.jsonのblobは `e8dcce4cd789d567072ddb5343123f9e5dba84dd` です。

- スマホでは導入を短くし、見積開始ボタンを主な操作にしました。重複した手順表示・見出し横の選択値・下部電話ボタンを非表示にしました。ヘッダー電話、選択項目、結果の変更ボタンは保持しています。

## 構成と変更の起点

ビルド不要のHTMLとdata.json、img配下の画像です。追加CSSはhead末尾の `First small simplification` コメントから。価格説明はPROMISE、FLOW、FAQ、GREETINGと、サイズ案内・PDF注意書き・申込欄の補足です。

公開はmain更新後のGitHub Pages標準「pages build and deployment」です。実行対象のSHAとActionsの成功を照合し、公開URLの最新文言と操作を確認してください。公開更新を行う場合は、その時点の承認と最新mainを確認してください。

## 再現する検査

リポジトリのルートで、追加パッケージなしに次を実行します。

```sh
node genkan-mitsumori/tests/verify-production.cjs
```

Git履歴がない場合は、基準HTMLファイルのパスを第1引数に渡せます。検査は4商品系統の1,761組合せ（性能×型×開き方）について色・鍵ごとの計算結果と選択補正を基準と比較し、選択スナップショット再適用、JS構文、フォーム属性、リンク、申込先、試作設定の混入も確認します。

この検査は現在の価格が正しいことや、カタログ照合の保証ではありません。金額の確認は別作業です。ブラウザー表示、iPhone実機、申込受信の完了を証明するものでもありません。

## 画面確認と残件

360/390/430px幅の横はみ出し、開始ボタン、各商品系統の切替、色・鍵の再選択、説明ダイアログを開閉後の戻る/進む、連打、結果の変更リンク、申込欄到達、電話/LINEリンクを確認してください。本番でテスト申込・電話・LINE送信・PDF記録を行う場合は、実データが送信されるため別途承認を確認してください。

価格説明は事業方針に基づく文言変更で、価格表の再確認は残件です。ブラウザーQAの実施範囲・公開コミット・配信結果の最終記録はユーザーのGoogle Drive側変更記録に残します。

対象リリースはこのHANDOFFを追加したコミット/PRです。履歴の書換え・force pushは行いません。後続の変更がないことを確認できる場合は、このリリースのsquashコミットを `git revert <release_sha>` し、レビュー後にmainへ反映します。後続の変更がある場合は、承認済み変更の該当差分だけを逆適用してください。リポジトリ全体を過去へ戻さないでください。
