玄関ドア かんたん見積（genkan-mitsumori）：本公開と電話番号の形チェック

作成日：2026-10-01 ／ 発案：福嶋智和 ／ 状態：GO（2026-10-01 福嶋さん「テスト公開の表示を外す。検索にも出るように。同じチェックを入れて」）

背景
・フクろう親方（公式サイトのAIチャット）で、玄関ドアの費用の質問が9月にいちばん多かった。親方から「お好きなドアを選ぶと工事費込みの金額が出るページ」としてこのページへ案内する（親方側の変更は fkenzai-ai-hisho の docs/requirements/20261001-genkan-mitsumori-link.md）
・お客様を案内する以上、テスト公開の表示は外し、検索にも出す
・申し込みの電話番号は空でなければ何でも通っていた（「あ」でも受け付ける）。返信できない申し込みを防ぐため、親方の相談フォームと同じ形のチェックを入れる

やること
1. 上部の「このページはテスト公開中です。」を外す。金額がカタログ価格をもとにした目安である旨の一文は残す
2. meta robots の noindex,nofollow を外す（検索に出る）
3. 申し込みの電話番号に形のチェックを入れる。判定は fkenzai-ai-hisho の ai-hisho/contact.js と同じ
 ・全角数字・全角ハイフン・長音記号は整えて読む。数字・ハイフン・空白・かっこ・先頭の+81だけ使える
 ・0から始まる10桁か11桁なら通す。違えば「電話番号は、0から始まる10桁か11桁でご入力ください。」と出して送らない
4. メールアドレスは任意のまま。入っているときだけ形を確かめる
5. 送る電話番号は、お客様が入れた形のまま（ハイフン付きなど）。数字だけに整えると、受け口のスプレッドシートが先頭の0を落とすおそれがあるため

やらないこと
・申し込みの受け口（GAS）側のチェック（別のプロジェクト。必要になったら別に行う）
・金額・値付けの変更

受け入れの条件
・ページ上部にテスト公開の文言が無い
・index.html に noindex が無い
・電話番号に「あ」「090-1234」を入れると送られず、お知らせが出る。「090-1234-5678」「０９６－１２３－４５６７」は通る（手元の Chromium で、受け口への送信を止めて確かめる）
