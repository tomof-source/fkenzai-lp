玄関見積LP 第1段の要件（2026-09-27 福嶋さんの指示で確定）

決まったこと
・値付けは当面いまのまま：メーカー定価の60%＋取り付け工事60,000円＋処分・諸経費15,000円、消費税10%。あとで変えられるように、画面の先頭の定数1か所にまとめる
・写真掲載とアンケートに協力いただける方は5,000円引き（税込合計から引く）
・第1段は片開きと親子だけ。メーカーはLIXILリシェントだけ（ドアリモは後）
・公開は記事LPと同じ fkenzai-lp。申し込みだけGASで受ける
・7月の価格表とカタログの照合はAIが行う
・メーカーの商品写真はLPに載せてよい。写真はカタログから切り抜いた実物を使う。色はモデルごとにカタログから拾う
・見た目：背景は真っ白。アクセントは公式サイト（f-kenzai.com）の色。コーポレートカラーはあとで福嶋さんから指示

作るもの
1. カタログから写真と価格を取り出す仕組み（03_作業記録/tools/rechent_extract_lp.py）
   ・価格ページを座標つきで読み直し、7月の価格表と1行ずつ照合する
   ・色ごとのドア写真、片開き・親子の写真、デザインの大きな写真、木目の色見本を、PDFに埋め込まれた画像のまま取り出す
   ・色の区分：カタログ109ページの一覧で木目調・アルミ色、デザインページの「セレクト」印でセレクトカラー
2. LP本体（04_成果物/genkan-mitsumori）
   ・断熱の性能 → 開き方 → デザイン → 色 → 鍵 → 協力値引き の順に選び、工事費込みの税込金額と内訳、その金額で入るサイズの範囲を出す
   ・申し込みフォーム：必須は名前・電話・住所・知ったきっかけ。任意で希望日・色見本の貸出・窓も見てほしいか・玄関の写真・メモ
3. 申し込みの受け口（GASウェブアプリ）
   ・申し込みをスプレッドシートに1行ずつ記録し、写真はDriveのフォルダに保存し、tomo.f@f-kenzai.com にメールで知らせる
   ・スプレッドシートとフォルダのIDはスクリプトプロパティで持つ

受け入れの条件
・価格表とカタログの照合で、LPに出す全行が一致していること（一致しない行はLPに出さない）
・iPhoneの幅で横にはみ出さないこと
・申し込みを1件試しに送り、台帳に1行増え、メールが届くこと

今回やらないこと
・ドアリモ、袖付き・両開き・ランマ付き・引戸、自宅写真との合成
・M16型（カタログに個別の価格ページが無い特別品）
